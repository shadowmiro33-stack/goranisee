URL로 수집

지금 수집 (기본) — 버튼을 누르면 Cloudflare의 한국 데이터센터에서 브라우저가 떠서 모바일 화면으로 열고 페이지마다 바로 여기에 올립니다. 해외 IP 차단·"네트워크 오류" 창 문제가 없습니다. 사이트 전체는 링크를 따라가며 진행 상황이 아래에 실시간으로 뜹니다(창을 닫지 마세요). 무료 한도 하루 브라우저 10분 ≈ 페이지 40~50개. "신청까지 흐름"만 GitHub 서버(해외)로 돕니다.

복붙용 프롬프트

수집한 데이터를 AI 분석 요청문으로 정리한 것입니다. 복사해서 Claude 등에 붙여 넣으면 경쟁사별 소구점·퍼널 흐름·광고/추천 노출 방식을 비교 분석해 줍니다. 필터(화면·경쟁사)가 반영됩니다.

수집 버튼(즐겨찾기) 만들기

확장 프로그램 설치 없이, 즐겨찾기 바의 버튼 하나로 경쟁사 페이지를 수집합니다. 수집할 사람마다 한 번씩 아래 절차를 하면 됩니다.

  1. 어드민 비밀번호를 입력하고 버튼 생성을 누릅니다.
  2. 크롬에서 Ctrl+Shift+B로 즐겨찾기 바를 켭니다.
  3. 아래 파란 버튼을 즐겨찾기 바로 드래그해 놓습니다. (드래그가 안 되면 "수동 추가" 안내를 따르세요.)
  4. 경쟁사 사이트에서 그 즐겨찾기를 클릭 → 오른쪽 위에 패널이 뜨면 경쟁사 이름·단계 선택 → 이 페이지 캡처.

드래그가 안 될 때: 수동 추가
  1. 즐겨찾기 바 빈 곳에서 우클릭 → 페이지 추가…
  2. 이름: 퍼널 수집
  3. URL: 아래 코드 복사를 눌러 복사한 것을 붙여넣기 → 저장

휴대폰에서 쓰기 (한국 IP로 보완 수집)

자동 수집(해외 러너)이 막히거나 사이트 오류 창이 남은 페이지는 휴대폰에서 같은 버튼으로 캡처하면 됩니다. 한 번만 설정하세요.

  1. 위에서 버튼 생성 후 코드 복사 → 휴대폰으로 보냅니다(카카오톡 "나에게" 등). 코드에 비밀번호가 들어 있으니 외부 공유 금지.
  2. 아이폰 Safari: 아무 페이지에서 공유 → 즐겨찾기 추가(이름 퍼널 수집) → 즐겨찾기 목록에서 편집 → 주소를 지우고 복사한 코드를 붙여넣고 저장.
    안드로이드 Chrome: 메뉴 → 북마크 추가 → 북마크 편집 → URL을 복사한 코드로 교체.
  3. 경쟁사 페이지를 연 뒤 주소창에 "퍼널 수집"이라고 입력 → 나타나는 즐겨찾기를 탭 → 패널에서 경쟁사·단계 선택 → 캡처. 전체 화면 스크린샷은 1~2분 뒤 어드민이 만들어 넣습니다.

※ 즐겨찾기 버튼은 보이는 화면 대신 페이지 구조를 보내고 어드민이 전체 화면 스크린샷을 생성합니다. 사이트가 외부 전송을 막으면 어드민 저장 창이 자동으로 열립니다(팝업 허용 필요).
