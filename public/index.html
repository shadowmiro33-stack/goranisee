화면 경쟁사

URL로 수집 (archive.org의 "Save Page Now"처럼)

경쟁사 페이지 주소를 넣으면 GitHub Actions 러너가 그 페이지를 모바일 화면으로 열어 CTA·추천 영역·팝업·소구점과 전체 스크린샷을 수집해 여기로 보냅니다. 회사 IP는 남지 않습니다. 보통 1~2분 걸립니다. 신청까지 흐름 따라가기를 켜면 첫 화면에서 시작해 리스트 → 상세 → 신청 버튼까지 실제로 따라가며 단계별로 캡처하고 신청까지의 탭 수·입력 폼·로그인 필요 여부를 측정합니다(입력·제출은 하지 않음, 모바일 화면, 3~4분). 전체 페이지 수집을 켜면 같은 도메인의 링크(사이트맵 포함)를 따라 최대 N페이지를 모두 캡처하고 URL로 단계(첫 화면/목록/상세/신청/이벤트/기타)를 자동 분류합니다(모바일, 페이지당 약 20초). 로그인이 필요한 페이지는 수집되지 않으니 확장·즐겨찾기로 직접 캡처하세요.

복붙용 프롬프트

수집한 데이터를 AI 분석 요청문으로 정리한 것입니다. 복사해서 Claude 등에 붙여 넣으면 경쟁사별 소구점·퍼널 흐름·광고/추천 노출 방식을 비교 분석해 줍니다. 필터(화면·경쟁사)가 반영됩니다.

수집 버튼(즐겨찾기) 만들기

확장 프로그램 설치 없이, 즐겨찾기 바의 버튼 하나로 경쟁사 페이지를 수집합니다. 수집할 사람마다 한 번씩 아래 절차를 하면 됩니다.

  1. 어드민 비밀번호를 입력하고 버튼 생성을 누릅니다.
  2. 크롬에서 Ctrl+Shift+B로 즐겨찾기 바를 켭니다.
  3. 아래 파란 버튼을 즐겨찾기 바로 드래그해 놓습니다. (드래그가 안 되면 "수동 추가" 안내를 따르세요.)
  4. 경쟁사 사이트에서 그 즐겨찾기를 클릭 → 오른쪽 위에 패널이 뜨면 경쟁사 이름·단계 선택 → 이 페이지 캡처.
